# /betabot/python_scripts
This folder contains usefull python scripts created for the BetaBot.

## CREATING NEW SCRIPTS
Every bash script must begin with 
```
#!/usr/bin/env python
#-*- coding: utf-8 -*-#
```
After creating a script, make it executable by running 
```
sudo chmod +x ScriptFileName
```
To run a script run 
```
python3 /betabot/python_scripts/ScriptFileName
```
