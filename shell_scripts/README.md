# /betabot/shell_scripts
This folder contains usefull bash scripts created for the BetaBot.

## SOURCE THIS FOLDER
Source the shell scripts folder each time your launch a terminal session
```
echo "source /betabot/shell_scripts/" >> ~/.bashrc
```

## CREATING NEW SCRIPTS
Every bash script must begin with 
```
#!/bin/bash 
```
After creating a script, make it executable by running 
```
sudo chmod +x ScriptFileName
```
